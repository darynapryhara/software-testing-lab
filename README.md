Практична робота: Створення автоматизованого тесту за допомогою штучного інтелекту та публікація коду на GitHub
Вебсайт для тестування
Посилання: https://the-internet.herokuapp.com/
Опис трьох автоматизованих перевірок
Перевірка заголовка сторінки: відкриває головну сторінку сайту та перевіряє, чи заголовок сторінки дорівнює "The Internet".
Перевірка елементів сторінки: перевіряє наявність головного заголовка h1 з текстом "Welcome to the-internet" та видимість посилання "Form Authentication".
Перевірка переходу на іншу сторінку: натискає на посилання "Form Authentication" і перевіряє перехід на сторінку /login із заголовком "Login Page".
Інструкція із запуску тесту
Встановіть Node.js (https://nodejs.org/) та Visual Studio Code.
Створіть папку для проєкту та завантажте туди файл test.spec.js.
Відкрийте термінал у папці проєкту та виконайте команди:
npm init -y
npm install playwright
npx playwright install chromium
Запустіть тест командою:
node test.spec.js

Використаний інструмент ШІ: Gemini
